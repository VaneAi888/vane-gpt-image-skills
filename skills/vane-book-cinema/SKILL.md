# 书页里的电影

从一本书出发，找到有文本依据、值得呈现的场景或观点，制作原创电影感海报。忠实理解书，不等于所有画面都必须是原文中描写过的镜头：明确区分原书事实、对主题的解读、视觉隐喻和为构图补充的创作。

## 理解书籍

- 确认用户提供的书名、作者、版本和素材。书名歧义影响内容时，优先用作者、语境或可靠资料消歧；仍无法判断时询问。指定段落或资料优先于泛泛的书籍印象；用户提供的解读应按其意图使用，不冒充原作者观点。
- 获取必要的内容依据：优先查原文、用户提供的材料或出版社资料；需要核实细节且具备联网条件时查阅可靠来源，保留可分享的出处。不能查阅完整原书时，不暗示已经读过；资料不足时说明依据范围，只使用有把握的细节，不编造情节、引文、人物或章节。尊重用户不联网或不剧透的要求。
- 区分小说与非虚构作品：小说聚焦人物关系、场景、冲突或母题；非虚构作品聚焦论点、论证、案例或概念，不能虚构书中不存在的事实场景来证明其论点。版本差异、真实人物外貌和文字引述有疑问时不擅自补全。

## 从书到画面

1. 根据用户想要的成品和侧重点，选取有依据的切口：关键场景、主要人物、贯穿意象或抽象主题。必要时提供 2–3 个明显不同且各有依据的视觉方向，说明各自依据和表达；用户已指定方向或要求直接生成时，直接行动。
2. 对选定方向简要说明「书中依据 → 视觉转译」：哪些内容来自书，哪些是诠释、隐喻或画面补充。不要把隐喻说成原文情节，也不要把改编电影的演员、镜头或海报当作原著内容；可按用户要求参考指定改编版本并注明。
3. 构建电影海报：确定 2:3 竖版或用户指定尺寸、主体、构图层级、焦点、氛围、配色、片名及作者信息。可使用适合书意的留白、人物剪影、场景纵深、物件特写、画中画、双重曝光等构图；不依赖其他已安装技能。用户明确要求借用其他可用版式库时尊重其选择。
4. 用户未指定时默认一张；要求系列时，为每张选不同的文本切口，统一画幅、视觉语言及文字层级，避免简单重复。用户要求不剧透时避开关键转折及结局。

## 交付

- 请求方案或提示词时，给出能执行的构图和文字层级，并附简短的书中依据；如果只要求一个结果，避免强制额外轮次。
- 请求生成、试做或修改图片时，使用可用图像工具实际生成或编辑；工具不可用时坦诚说明，提供可复制的完整提示词与画面方案。提供的参考图按其指定用途使用。
- 用户指定的书名、作者和文字原样保留。无可靠依据时不编造引文、电影改编信息、演员、片方、奖项或背书；需要准确排字但模型无法实现时，可先生成无字底图并说明后期叠字方案。
- 检查画面与已核实的关键细节、所选视觉隐喻、文字准确性、缩略图可读性和裁切。未看到实际图片时不声称完成视觉检查；实际图像仅为创意演绎，不暗示官方授权或真实影像。
