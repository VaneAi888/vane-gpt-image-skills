# vane-x文章-像素品牌视觉

以已确认的 C 版视觉制作封面、正文配图。具体任务、标题、主题和用户后续修改优先；不要把测试文章内容当成固定文案或每张图都套用同一构图。若用户要求其他风格，按用户指定执行。

## 已确认的共同视觉

- 色彩参考 [X 资料背景](assets/profile-banner.png)：温暖浅色、浅紫为主，深紫和中紫用于地面、边缘、阶梯形像素结构及局部对比，少量荧光黄绿点缀。整体有明显深色层次，但避免整张图近乎全深紫，也避免只剩浅色。
- 像素阶梯形边缘与精致的 3D 体素元素，干净、有空间、亲切而有科技感。文字保持端正、精致、适当偏小，有层级且清晰，避免过粗、斜体和过度拥挤。
- 需要人物时参考 [像素头像](assets/pixel-avatar.png)：短黑发、白 T 恤，形象跨图保持一致；根据内容决定是否出现，不强制每图出镜或固定坐在电脑前。不要擅自改变或虚构其个人身份。

## X 文章封面

- 参考 [已通过测试的封面](assets/cover-example.png) 的字体、层级、留白和单重点处理。默认严格 5:2，通常交付 2000 × 800；用户给出其他尺寸时遵从用户。
- 准确完整呈现用户指定的标题，按语义断行。通常只挑一个最值得突出的短语，以荧光黄绿的像素色块和深紫文字突出；其余文字以深紫色正常排版。具体重点随标题变化，勿固定突出某个词。
- 右侧插画必须随主题重新设计，用能解释主题的具体元素；是否出现像素角色依内容决定。不要把示例里的剪辑台和话题机械复制到其他选题。

## 文章正文配图

- 参考 [生图流程样例](assets/article-scenes.png) 与 [封面和正文对比样例](assets/article-gallery.png) 的配色和清晰度。构图随信息变化：对比、场景、流程、概念隐喻、网格展示均可，先选最能解释内容的方式，不要每张都画成封面或统一卡片。
- 每张图只承担一项清晰的表达，图中文字精简、准确、方便手机阅读。参考图仅展示信息组织方式，不强制固定数量；涉及枚举时，不要把部分示例误标成完整展示。
- 测试配图使用横版 16:9；若用户提供比例或平台要求，按其要求。静态示意图不能称为真实 GIF 或视频。

## 制作和交付

优先使用可用的图像生成/编辑工具，将相关参考图作为视觉参考：封面用背景与封面参考；正文用背景和最匹配的信息组织示例；人物出现时加入头像参考。保持用户给出的标题和内容，不捏造产品功能。无需为一般构图反复确认；主题不明时先询问。

检查文字、裁切、比例、人物和主题相关性；明显错误则修正。封面比例如仅有极小像素误差且不损失文字，可微裁并调整到严格 5:2，避免拉伸变形。将最终文件保存到当前工作区，文件名清楚且不覆盖现有成果，提供可点击链接。用户尚未确认的版本应称为测试稿。
