## 📦 统一安装入口

**检查日期：2026-11-12**

- 在临时目录分别测试安装全部 Skill、单独安装各个 Skill，以及必要指令、脚本和参考素材。
- 模拟已有同名 Skill：安装器拒绝覆盖原文件；使用 `--all` 时会在复制前检查全部目标，避免因同名目录而只安装一部分。
- 三个 Skill 的结构通过本地 Skill 校验。上述检查没有修改用户已安装的 Skill，也不替代在其他操作系统或实际图像生成环境中的测试。

后续增加 Skill 时，建议记录使用的输入、生成条件、实际结果和发现的问题，并将“实际运行通过”与“仅检查文件或样例”分开描述。
