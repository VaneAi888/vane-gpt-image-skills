# 📚 书页里的电影

[← 返回 Skill 合集首页](../README.md)

如果一本书有一张电影海报，它会是什么样子？从书中的人物、场景、意象或观点出发，把阅读时的想象变成一张电影感海报。

**36 本书籍效果示例** · **4 组完整预览** · **默认竖版 2:3**

## ✨ 适合做什么

- 为小说、纪实或非虚构作品设计电影感海报。
- 根据指定的段落、人物、场景或主题，设计画面、提示词或一组海报。
- 将原书内容和视觉隐喻分别说明，也可以按要求避免剧透。

## 🚀 开始使用

**1. 安装 Skill**

按照[统一安装教程](installation.md)获取合集，选择安装 `vane-book-cinema`。四张预览图会随 Skill 一并安装。

**2. 提供书籍和创作想法**

告诉它书名、作者，以及想要表现的人物、段落或主题。你也可以上传相关文字或图片，并指定尺寸、语言、风格及是否避免剧透。例如：

> 使用 $vane-book-cinema，为《小王子》制作一张电影感海报，突出小王子与玫瑰的关系。不要剧透，先说明画面依据。

> 使用 $vane-book-cinema，根据我提供的非虚构书籍摘要设计海报，用一个简洁的视觉隐喻表达核心观点，不要编造书里的案例。

**3. 检查成品**

核对书名、作者、画面细节和文字；确认哪些来自书中，哪些属于创意演绎。生成的文字不够准确时，可先制作无字底图再排版。

## 🛠️ 运行环境与说明

- 需要支持 Skill 的环境；生成或修改图片时还需可用的图像生成工具。
- 默认一张 2:3 竖版海报；可以要求其他尺寸或系列作品。
- 提供原文、摘要或可靠来源有助于核对内容。无法获取完整书籍时，Skill 应说明依据范围，不编造情节或引文。
- 36 张样图展示的是不同书籍，不是 36 种固定版式或保证生成完全相同的结果。
